# Support Resources for Kant (`kantc`)

Welcome to the Kant project community support channels. Whether you have questions regarding
epistemic language semantics, compiler architecture, tooling integration, or contribution workflows,
the resources below are available.

---

## 1. Official Support Channels

### GitHub Discussions
For architectural debates, general questions, RFC design ideas, and community sharing:
- **Discussions:** [GitHub Discussions](https://github.com/azmyayman-maker/KANT/discussions)
- Categories:
  - *Announcements*: Release notifications and community milestones.
  - *Q&A*: How to write Kant programs, configure the compiler, or run tools.
  - *RFCs*: Proposals for language grammar, effect system enhancements, or runtime features.
  - *Show and Tell*: Projects and sidecars built with Kant.

### GitHub Issues
For bug reports, compiler crashes, incorrect error diagnostics, and feature requests:
- **Issue Tracker:** [GitHub Issues](https://github.com/azmyayman-maker/KANT/issues)
- Please use the appropriate issue template (Bug Report, Feature Request, or Spec Discrepancy).
- Ensure reproduction code includes `#![kant(v0.1)]` header and CLI flags.

### Real-Time & Chat Communities
- **Discord:** [Join the Kant Community Discord](https://discord.gg/kant-lang)
- **Matrix / IRC:** `#kant:matrix.org`

---

## 2. Community Triage Service Level Objectives (SLO)

Our maintainers and community leads strive to meet the following response targets:

| Issue Severity | First Response Target | Resolution Target |
| :--- | :--- | :--- |
| **Critical Bug (Compiler Panic / Codegen Miscompilation)** | Within 24 hours | Within 7 business days |
| **Security Vulnerabilities** | Within 48 hours | See [SECURITY.md](SECURITY.md) |
| **General Bug Reports & Regressions** | Within 3 business days | Next release cycle |
| **Documentation Clarifications & PRs** | Within 5 business days | Rolling basis |
